### 커밋에 Gitmoji 사용
- gitmoji를 사용하고, 커밋 메시지를 아래처럼 형식화합니다.
```
:emoji: I do somthing terrible on the code
📝 routes.md 문서화
```

```
:emoji: I do somthing terrible on the code

I litterally make something terrible thing on the code.
The `terrible thing` includes, spegettize the code, and make Promise
to always await its execution, and some 502 code.
```

- 사용할 gitmoji는 아래 형식과 같습니다.
- ⚡️: improve performance, structure or design
- 🔥: remove some code or files
- 🐛: Fix a bug
- 🚑️: critical hotfix
- ✨: new feature
- 📝: documentize
- 🚀: commit for deploy
- 다른 궁금한 이모지가 있으면 [여기에서](https://gitmoji.dev/) 볼 수 있습니다. 근데 우리는 안 쓸거에요

- 여기에 작성한 내용은 전부 정리해서 `CONTRIBUTING.md`에 작성해주세요
- Commit format, Code review, Code format.
