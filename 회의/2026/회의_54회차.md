SIG
애드혹 SIG: **SIG**, 애드혹
PS 대회 참가 소모임: **소모임**, CP
PS 팀연습 SIG: **SIG**, CP
군입대 소모임: **소모임**, 군대

=====

/sig: SigList<sigs = 시그 전체>
/sig/category/[tag_text]: SigList<sigs = 태그로 검색한거>

SigList
SigList 안에서, major 가 아닌 Tag 가 검색이 가능하겠지.
sig 가지고 있는 거중에 태그로 검색한거

=====

/sig: SigList<sigs = 시그 전체>
/sig/category/[tag_text]: SigList<sigs = 시그 전체, tag = [tag_text]>

SigList
SigList 안에서, 모든 Tag 를 띄워주고, 기본 적용은 [tag_text]
기본 적용에서 fetch 해서 띄우고
태그 업데이트 되는거 있으면 sigs 에서 업데이트를 함. 아니면 fetch 를 새로 하던가

=====

C

I. Create SigTag_rel by normal user
II. Create Tag by admin user

R

I. Read by Sig ID
II. Read by Tag Text

U

X.

D
