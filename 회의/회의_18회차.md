## 논의사항

### BE 구현
- 유저가 프로필 이미지를 등록할 수 있게 만듧시다.
- **BE**
- BE는 User Data DB에 이미지를 url 형식으로 저장하는 Attribute를 추가해야 합니다
- 기본값이 있어야 합니다. 대충 public에다가 `default_profile_image.png` 같은거 만들어 놓읍시다.
- 등록은 두 가지 형태로 가능하게 할 건데, 한 가지 방법은 이미지 url을 등록하는 거고, 하른 하나는 이미지 자체를 전송하는겁니다. 이 경우 서버가 이미지를 저장한 뒤에 이미지 경로를 뭐 `/public/...` 이런 식으로 주면 되겠죠. 첫 번째 건 현재 구현되어있는 `/api/user/update` 기능으로 가능할거라 기대하고, 두 번째 방법은 별도의 라우트가 필요할 듯 합니다
- FE는 MyPage에 적절히 이미지 보여주고, 등록하는 버튼을 만듧시다.
- 그리고 OAuth로 로그인 하면 구글 계정의 프로필 이미지 url이 계정 정보로 같이 날라오는데, 최초 가입시 그걸로 프로필 이미지 등록합시다.

### 지원금 신청 페이지
- 시그 지원금 또는 피그 지원금 신청을 위한 페이지가 필요합니다.
- 제목 선택하고, 시그 or 피그 선택하고, 내용과 요금액 작성하고, 마지막으로 안내사항 체크 후 제출하면 지원금 신청이 완료됩니다.
- 지원금이 신청 되었을 때 어떤 방식으로 임원진한테 전달할까 생각을 좀 헀는데, 가장 나은 방법은 디스코드 봇으로 알리는 것 같습니다.
- **봇**
- 채널을 등록하고, request code를 하나 만들어서, 뭐 그냥 전달
- **조금 더 과학적인 방법**
- 모든 게시판에 대해서, 봇 또는 BE 서버가 feedback 채널을 등록할 수 있게 만들기
- 게시판 등록 시, 만약 feedback 채널이 등록되어있다면, 등록되어있는 채널에 내용을 전달
- 이후 읽기 권한은 executives로 쓰기 권한은 newcomers로 게시판을 만든다
